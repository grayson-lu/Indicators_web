# 每日企业微信推送系统

这是一个统一的企业微信每日推送模块，整合了所有推送功能，实现每天早上定时推送丰富的市场数据报告。

## 功能特性

### 📊 数据收集
- **Y指数数据**: 获取Y指数当前值及日/周/月变化
- **市场情绪**: 恐慌贪婪指数、情绪等级、极端币种比例、AHR999指数
- **市场宽度**: 新高/新低比例、涨跌比、A/D百分比
- **链上指标**: MVRV比率、稳定币供应量、交易所净流入、平均资金费率
- **波动率分析**: 30天/7天波动率、市场流动性

### 🎨 丰富内容
- **可视化表情**: 根据数据变化自动添加相应的表情符号
- **智能解读**: 自动分析指标含义，提供风险提示
- **多维度展示**: 涵盖技术面、情绪面、链上数据等
- **专业格式**: 使用Markdown格式，支持企业微信的富文本显示

### ⏰ 定时推送
- **默认时间**: 每天早上8:00自动推送
- **额外时段**: 09:30(早盘)、15:00(午盘)、21:00(晚盘)
- **灵活配置**: 支持自定义推送时间
- **连接测试**: 自动测试企业微信连接状态

## 安装依赖

```bash
pip install pandas numpy requests schedule
```

## 配置说明

### 环境变量
设置企业微信Webhook地址：
```bash
export WECHAT_WEBHOOK_URL="你的企业微信机器人Webhook地址"
```

### 数据文件
确保以下数据文件存在于 `y_data` 目录中：
- `y_idx.csv` - Y指数数据
- `market_sentiment.csv` - 市场情绪数据
- `market_breadth.csv` - 市场宽度数据
- `chain_metrics.csv` - 链上指标数据
- `volatility_data.csv` - 波动率数据

## 使用方法

### 命令行运行
```bash
python daily_wechat_push.py
```

### 作为模块使用
```python
from daily_wechat_push import DailyWechatPushSystem

# 初始化推送系统
push_system = DailyWechatPushSystem("你的Webhook地址")

# 发送每日报告
result = push_system.send_daily_report()
if result.success:
    print("推送成功")
else:
    print(f"推送失败: {result.message}")

# 发送简单文本
push_system.send_simple_text("测试消息")

# 发送Markdown内容
markdown_content = "## 标题\n**加粗**内容"
push_system.send_markdown(markdown_content)
```

### 创建定时任务
```python
from daily_wechat_push import create_daily_push_scheduler
import schedule
import time

# 创建调度器
push_system = create_daily_push_scheduler()

if push_system:
    # 运行调度器
    while True:
        schedule.run_pending()
        time.sleep(60)
```

## 日志文件

系统运行日志保存在 `daily_wechat_push.log` 文件中，包含：
- 数据收集状态
- 推送发送结果
- 错误信息和调试信息
- 性能统计

## 错误处理

系统具有完善的错误处理机制：
- **数据验证**: 自动验证数据完整性和有效性
- **异常捕获**: 捕获并记录所有异常情况
- **重试机制**: 支持失败重试（在企业微信基类中实现）
- **降级处理**: 部分数据失败时继续发送其他数据

## 扩展性

系统设计具有良好的扩展性：
- **模块化设计**: 数据收集、内容生成、推送发送分离
- **插件支持**: 易于添加新的数据源或推送平台
- **配置灵活**: 支持自定义时间、内容格式等
- **多线程**: 数据收集使用多线程提高效率

## 注意事项

1. **Webhook安全**: 妥善保管企业微信Webhook地址
2. **频率限制**: 企业微信机器人有发送频率限制
3. **数据更新**: 确保源数据文件及时更新
4. **时区设置**: 推送时间基于系统本地时间
5. **网络连接**: 确保网络连接稳定

## 故障排除

### 连接失败
- 检查Webhook地址是否正确
- 验证网络连接状态
- 查看日志文件获取详细错误信息

### 数据缺失
- 确认数据文件是否存在
- 检查文件格式和内容
- 验证数据收集权限

### 推送异常
- 查看 `daily_wechat_push.log` 日志文件
- 检查企业微信机器人状态
- 验证消息内容格式
